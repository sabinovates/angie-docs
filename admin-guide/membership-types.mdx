---
title: "Membership types"
description: "Define the categories members can belong to, and how long each lasts"
---

Membership types are the categories your association offers — for example, Regular, Lifetime, or Student — each with its own duration.

![Admin membership types page](/images/admin/membership-types.png)

Create a type with a name and a duration (a fixed number of months, "Lifetime," or "Until graduation" for school-linked associations). The duration drives when a member's card shows as expired and when [renewal reminders](/admin-guide/members) go out.

Editing or removing a type doesn't change the expiry already set for members already on it — it only affects new approvals going forward.
