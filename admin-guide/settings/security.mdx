Set association-wide security rules: how long an inactive admin session stays logged in, and the minimum password length required for members.

![Admin security settings](/images/admin/settings-security.png)

## Your own password and 2FA

From this page you can also change your own password and enable or disable two-factor authentication on your own account, the same way a [member](/member-guide/settings) does on theirs. You'll get an email confirming either change.

<Warning>
  If your association's platform-wide 2FA requirement is on, you'll be required to set up 2FA the next time you log in — it isn't optional at that point.
</Warning>
