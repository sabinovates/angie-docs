---
title: "Roles & permissions"
description: "Define what each admin role is allowed to do"
---

Roles control exactly what an admin user can see and do — not every admin needs full access.

![Admin roles & permissions page](/images/admin/roles.png)

Create a role, then toggle permissions for each area of the admin console (members, finance, communication, settings, and so on). Assign the role to a [user](/admin-guide/users), and their access updates immediately.

<Note>
  Permissions are enforced on every request, not just hidden from the menu — a user without finance access can't reach finance pages even by typing the URL directly.
</Note>
